SpeakType Cloud — Rust + Slint

本程式安裝於目前使用者帳號，不需要系統管理員權限。

從 0.1.0 NSIS 版升級：
1. 從系統匣退出舊版。
2. 透過 Windows「已安裝的應用程式」正常解除安裝舊版。
3. 重新執行此安裝程式，安裝到新的 SpeakType Cloud Slint 資料夾。
舊版解除安裝保留設定、歷史、錄音與 Credential Manager 金鑰。
本安裝程式會阻止仍存在的舊安裝，不會執行登錄檔中的命令。
若已解除舊版但新版安裝取消或失敗，程式會暫時未安裝；資料仍保留，可重試安裝。
登入時啟動請在新版設定確認勾選後按「儲存設定」；即使原本已勾選，也會重建目前程式的啟動項目。不會修改其他程式的啟動項目。

正常解除安裝只移除應用程式檔案與捷徑，保留使用者設定、紀錄、音訊與金鑰。
若要刪除歷史或金鑰，請先在程式的設定及歷史頁面明確操作。

Google AI Studio 金鑰由你自行輸入。啟用 Gemini 前請閱讀資料傳送與費用說明。
未啟用保存時，轉錄文字和音訊不會新增至歷史資料夾。
未配置可信簽章的版本停用自動更新；請由官方 GitHub Releases 手動下載。
